# Averitt Tools reference snapshot

The adjacent `index.html` is a source snapshot fetched from `https://tools.averitt.com/` on 2026-09-05. It is reference material only; the rendered page is implemented in the Askama templates under `templates/`.

## Local asset map

- `assets/img/averitt/brand/` — Averitt logos and the secure-login lock icon
- `assets/img/averitt/hero/` — header background image
- `assets/img/averitt/services/` — Ship, Track, and Manage photos
- `assets/img/averitt/tools/` — six shipping-tool icons
- `assets/img/averitt/social/` — footer social icons
- `assets/fonts/` — Font Awesome files used by the reference navigation and form styles
- `assets/styles/averitt-reference.css` — downloaded reference stylesheet, with only its local asset paths rewritten

The application keeps HTMX for local interactions while using the reference page's DOM classes and visual rules.
